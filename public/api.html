API pública e gratuita

Usa os dados do Dados da Banda nas tuas aplicações. A leitura é aberta e não precisa de chave: faz o pedido e recebe JSON ou CSV com a fonte de cada valor.

GET https://dadosdabanda.vercel.app/v1/series/bna_cambio_usd/observacoes?de=2004 { "id": "bna_cambio_usd", "nome": "Câmbio de referência USD/AOA (BNA)", "unidade": "AOA por USD", "periodicidade": "mensal", "fonte": "Frankfurter · referência BNA", "url_consulta": "https://api.frankfurter.dev/...", "observacoes": [ {"periodo": "2004-01", "valor": 85.47, "recolhido_em": "..."}, {"periodo": "2026-10", "valor": 909.09, "recolhido_em": "..."} ] }
Chave opcional
